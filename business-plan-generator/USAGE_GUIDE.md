# 📖 補助金経費項目プランナー - 使い方ガイド

## 🚀 クイックスタート

### 1. アクセス
ブラウザでアプリケーションを開いてください。
**アプリケーションURL**: https://3000-ieu0un839fe4ky1papyb6-dfc00ec5.sandbox.novita.ai

### 2. 基本情報の入力

#### 📋 入力項目
- **店舗名**: あなたの事業所名を入力
  - 例: `カフェレストラン さくら`
- **申請枠**: 該当する枠を選択
  - 通常枠: 上限50万円（一般的な小規模事業者）
  - 創業枠: 上限200万円（開業5年以内）
  - 賃金引上げ枠: 上限200万円（従業員の賃上げを行う場合）
- **インボイス制度対応**: 該当する場合はチェック
  - チェックすると補助上限額が+50万円

### 3. 経費項目の追加

#### ステップ1: カテゴリーを理解する
経費入力フォームの上に、10個のカテゴリーボタンがあります。

```
💡 各経費カテゴリーの詳細（対象/対象外、注意点、採択事例）を確認できます
```

**例**: 「機械装置等費」ボタンをクリック
→ モーダルが開き、以下の情報が表示されます：
- 📖 説明: どんな費用か
- ✅ 対象となるもの: 購入できる機器の例
- ❌ 対象外: 認められない例
- ⚠️ 注意点: 申請時の注意
- 💡 採択事例: 実際に採択された事例

#### ステップ2: 経費を追加
1. 「+ 経費を追加」ボタンをクリック
2. フォームに入力:
   - **カテゴリー**: プルダウンから選択
   - **品名**: 購入する物品やサービス名
   - **詳細説明**: 販路開拓にどう役立つか
   - **金額**: 見積もり金額（税込）

**入力例**:
```
カテゴリー: 機械装置等費
品名: 業務用真空包装機
詳細: テイクアウト商品の品質向上と日持ち改善により新規顧客開拓
金額: 300,000円
```

3. 「追加」ボタンをクリック
4. 必要な経費をすべて追加

### 4. 自動チェック機能の確認

#### ⚠️ ウェブサイト関連費の警告
「ウェブサイト関連費」を追加した場合、自動的にチェックされます。

**上限ルール**: ウェブサイト関連費は総額の1/4（25%）まで

**表示例**:
```
✅ ウェブサイト関連費は上限内です
   あと ¥150,000 まで追加できます
```

または

```
⚠️ 警告：ウェブサイト関連費が上限を超えています！
   超過分: ¥50,000
```

### 6. スケジュール管理

#### 📅 締切日の設定
1. 「申請スケジュール管理」セクションを開く（▶をクリック）
2. 申請締切日を入力
3. 自動的に残り日数が表示される

**カウントダウン表示**:
- 15日以上: `⏰ あと 30日` （青）
- 8-14日: `⏰ あと 10日` （黄）
- 1-7日: `⏰ あと 3日` （赤・点滅）
- 当日: `🔥 本日締切！`

#### ✅ 準備チェックリスト
7つの必須項目がリスト表示されます：
- 経営計画書の作成（様式2）
- 補助事業計画書の作成（様式3）
- 経費明細表の作成（様式4）
- 見積書の取得（全ての経費項目）
- 事業要件の確認（販路開拓に該当するか）
- 必要書類の準備（登記簿謄本など）
- 電子申請システムの利用登録

#### 🔔 自動リマインダー
締切日に応じて、重要な日付が表示されます：
- 2週間前: 書類の最終確認を開始
- 1週間前: 申請書提出の準備完了（黄色警告）
- 3日前: 最終チェック＆提出（赤色緊急）

### 7. データの保存

#### 💾 下書き保存
1. ヘッダーの「下書き保存」ボタンをクリック
2. 保存完了メッセージが表示される
3. ブラウザを閉じても、次回自動的に読み込まれる

**保存されるデータ**:
- 店舗名
- 申請枠
- インボイス対応状況
- すべての経費項目
- 申請締切日
- 保存日時

#### 🔄 自動読み込み
ページを開くと、前回保存したデータが自動的に復元されます。

### 8. PDF出力

#### 📄 PDFダウンロード
1. すべての経費を入力
2. ヘッダーの「PDF出力」ボタンをクリック
3. PDFファイルがダウンロードされる

**PDFの内容**:
- 事業者情報
- 申請枠とインボイス対応状況
- 全経費項目の詳細リスト
- 申請総額
- 予想受給額
- 自己負担額

**ファイル名**: `expense-plan-{店舗名}.pdf`

## 💡 使用のコツ

### 経費計画のポイント
1. **販路開拓との関連を明確に**
   - 各経費が「新規顧客獲得」や「売上向上」にどう貢献するか説明
   
2. **見積書を先に取得**
   - 正確な金額で計画を立てる
   
3. **ウェブサイト関連費に注意**
   - 全体の25%を超えないように調整
   
4. **複数の見積もりを比較**
   - 同じ物品でも複数業者から見積もりを取る

### 効率的な使い方
1. **カテゴリー詳細を先に確認**
   - 対象・対象外を理解してから入力
   
2. **こまめに保存**
   - 大量の経費を入力する際は定期的に保存
   
3. **スケジュールを最初に設定**
   - 締切から逆算して計画を立てる

## ⚠️ よくある注意点

### 対象外になりやすい経費
- 既存設備の単純な更新・修理
- 汎用性の高いパソコン・タブレット
- 日常的な消耗品
- 販路開拓と関連のない経費

### ウェブサイト関連費の制限
- ECサイト構築も「ウェブサイト関連費」
- SNS広告費用は「広報費」
- 全体の1/4を超えた分は補助対象外

### 補助金の注意事項
- ⚠️ 補助金は**後払い**
- 事業実施後の実績報告が必要
- 先に全額を自己負担して支払う必要がある

## 🆘 トラブルシューティング

### データが消えた
→ 「下書き保存」を使用していない場合、ブラウザのキャッシュをクリアするとデータが消えます。こまめに保存してください。

### PDFが文字化けする
→ 日本語フォントが含まれていない場合があります。後日対応予定。

### 警告が消えない
→ ウェブサイト関連費の金額を減らすか、他の経費を増やして全体のバランスを調整してください。
