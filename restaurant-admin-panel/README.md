# 🎛️ Restaurant Admin Panel (管理者向けアプリ)

**レストラン管理者がメニュー管理・QRコード生成・アクセス分析を行う管理画面**

## 📋 概要

Restaurant Admin Panelは、レストランの管理者がメニューを管理し、QRコードを生成し、アクセス分析を行うための専用Webアプリケーションです。

## ✨ 主要機能（管理者向け）

### 📊 ダッシュボード
- **統計サマリー**: 総メニュー数、対応言語数、人気メニュー数、総閲覧数を一目で確認
- **最近の活動**: メニュー更新やQRコードダウンロードの履歴
- **クイックアクション**: よく使う機能に素早くアクセス

### 📱 QRコード生成機能
- **簡単生成**: ワンクリックでメニュー用QRコードを作成
- **ダウンロード**: PNG形式で高解像度QRコードを保存
- **印刷機能**: テーブル用QRコードを直接印刷
- **URL表示**: 生成されたメニューURLを確認・共有

### 🍽️ メニュー管理機能
- **カテゴリ管理**: 前菜、メイン、デザートなどのカテゴリ分け
- **メニュー項目編集**: 名前、説明、価格、画像の編集
- **多言語管理**: 各言語ごとの翻訳内容を確認・修正
- **アレルギー情報**: アレルギー情報や食事制限対応の設定
- **バッジ設定**: 人気メニューや季節限定メニューのバッジ管理

### 📊 アクセス分析機能
- **言語別閲覧数**: どの言語で何回閲覧されたかを集計
- **人気メニューTOP10**: 最も閲覧されたメニューをランキング
- **時系列データ**: 日別・週別・月別のアクセス推移
- **インサイト**: データに基づく販売戦略の提案

### ⚙️ 設定機能
- **レストラン情報**: 店名、住所、電話番号、メールの管理
- **対応言語**: サポートする言語の選択
- **データエクスポート**: メニューデータのJSON形式エクスポート
- **データインポート**: 既存データの一括インポート

## 🚀 起動方法

### 開発環境

```bash
# プロジェクトディレクトリに移動
cd /home/user/webapp/restaurant-admin-panel

# 依存関係のインストール
npm install

# 開発サーバーの起動（ポート3002）
npm run dev
```

開発サーバーは http://localhost:3002 で起動します。

### 本番ビルド

```bash
# ビルド
npm run build

# 本番サーバーの起動
npm start
```

## 🎯 使い方（管理者向け）

### 1. ダッシュボードの確認

ログイン後、ダッシュボードで以下を確認：
- 総メニュー数
- 対応言語数
- 人気メニュー数
- 総閲覧数と推移

### 2. QRコードの生成

1. ダッシュボードの「QRコード生成」ボタンをクリック
2. 表示されたQRコードを確認
3. 「PNG形式でダウンロード」または「印刷」を選択
4. QRコードをテーブルやメニュー表に設置

### 3. メニューの管理

1. 「メニュー管理」に移動
2. カテゴリを選択
3. メニュー項目の追加・編集・削除
4. 各言語の翻訳を確認・修正
5. 変更を保存

### 4. アクセス分析

1. 「アクセス分析」に移動
2. 言語別閲覧数を確認
3. 人気メニューTOP10をチェック
4. インサイトを参考に販売戦略を立案

### 5. データのエクスポート/インポート

**エクスポート:**
1. 「設定」に移動
2. 「データエクスポート」をクリック
3. JSON形式でメニューデータを保存

**インポート:**
1. 「設定」に移動
2. 「データインポート」をクリック
3. JSON形式のファイルを選択
4. データを確認して読み込み

## 🎨 デザインの特徴

### カラースキーム（管理者向け）
- プライマリ: ブルー系（#0ea5e9）
- サイドバー: ダークグレー（#1f2937）
- アクセント: グリーン、イエロー、パープル
- 背景: ライトグレー（#f8fafc）

### レイアウト
- **カードベース**: 情報を整理してカード表示
- **グリッドシステム**: レスポンシブな統計カード
- **スティッキーヘッダー**: 常にナビゲーションにアクセス可能

## 🔧 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **アイコン**: Lucide React
- **QRコード**: qrcode.react
