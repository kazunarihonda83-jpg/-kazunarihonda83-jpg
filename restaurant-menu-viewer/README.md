# 🍽️ Restaurant Menu Viewer (ユーザー向けアプリ)

**顧客がQRコードスキャンでアクセスする多言語メニュー閲覧アプリ**

## 📋 概要

Restaurant Menu Viewerは、レストランの顧客が自分のスマートフォンでQRコードをスキャンして、母国語でメニューを閲覧できるWebアプリケーションです。

## ✨ 主要機能（ユーザー向け）

### 🌍 多言語表示
- **8ヶ国語対応**: 日本語、英語、中国語（簡体/繁体）、韓国語、フランス語、スペイン語、タイ語、ベトナム語
- **自動言語検出**: ブラウザの言語設定から自動的に最適な言語を選択
- **ワンタップ切り替え**: ヘッダーの言語セレクターで簡単に切り替え

### 🔊 音声読み上げ機能
- 各メニュー項目の名前と説明を音声で聞ける
- 正しい発音で料理名を確認可能
- 多言語対応の音声合成

### 🖼️ ビジュアルメニュー
- 料理の写真付きメニュー表示
- 人気メニューと季節限定メニューのバッジ
- 見やすいカードレイアウト

### 🚫 アレルギー・食事制限情報
- 詳細なアレルギー情報表示（卵、乳、小麦、甲殻類など）
- ベジタリアン、ビーガン、ハラール、グルテンフリー対応表示
- 視覚的なアイコンで一目で確認

### 📱 モバイルファースト設計
- スマートフォンでの閲覧に最適化
- タブレット、PCでも快適に表示
- タッチ操作に対応

## 🚀 起動方法

### 開発環境

```bash
# プロジェクトディレクトリに移動
cd /home/user/webapp/restaurant-menu-viewer

# 依存関係のインストール
npm install

# 開発サーバーの起動（ポート3001）
npm run dev
```

開発サーバーは http://localhost:3001 で起動します。

### 本番ビルド

```bash
# ビルド
npm run build

# 本番サーバーの起動
npm start
```

## 📱 使い方（顧客向け）

### 1. アクセス
- レストランのテーブルにあるQRコードをスキャン
- またはURLに直接アクセス

### 2. 言語選択
- 自動的に母国語が選択されます
- 右上の地球儀アイコンから言語を変更可能

### 3. メニュー閲覧
- スクロールしてメニューを確認
- 写真を見ながら料理を選択

### 4. 詳細確認
- 🔊ボタンをタップして音声で料理名を聞く
- アレルギー情報や食事制限対応を確認
- 価格を確認

### 5. 注文
- 気に入った料理をスタッフに伝える
- または注文システムと連携（将来実装予定）

## 🎨 デザインの特徴

### カラースキーム
- プライマリ: ブルー系（#0ea5e9）
- アクセント: グリーン、イエロー、レッド
- 背景: グラデーション（ブルー→インディゴ→パープル）

### レイアウト
- **カードベース**: 各メニュー項目を独立したカードで表示
- **グリッドシステム**: レスポンシブな3カラムレイアウト
- **スティッキーヘッダー**: スクロールしても言語選択が可能

### アニメーション
- フェードイン効果
- ホバーエフェクト
- スムーズなトランジション

## 🔧 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **アイコン**: Lucide React
- **音声**: Web Speech API
