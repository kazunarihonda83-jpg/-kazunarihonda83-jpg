# 🍽️ RestaurantTranslate - 多言語レストランメニュー翻訳システム

**インバウンド対応・QRコード対応の多言語レストランメニュー管理システム**

## 📋 概要

RestaurantTranslateは、飲食店向けの多言語メニュー翻訳・QRコード生成システムです。外国人観光客の増加に対応し、レストランのメニューを複数言語で提供し、アレルギー情報や食事制限にも対応します。

## ✨ 主要機能

### 🌍 【1】多言語自動翻訳機能（中核）
- **対応言語**: 日本語、英語、中国語（簡体/繁体）、韓国語、フランス語、スペイン語、タイ語、ベトナム語
- **飲食業専用辞書**: 「出汁」→「Dashi broth」など、一般翻訳では正確に訳されない専門用語に対応
- **AI翻訳エンジン**: フォールバック機能付きの高精度翻訳
- **カスタム翻訳**: 店舗独自の翻訳を保存・管理可能

### 📱 【2】QRコードメニュー生成機能
- テーブル・商品ごとにQRコード発行
- スマホでスキャンして自動的に母国語表示
- 言語自動判定機能
- QRコードのダウンロード・印刷機能

### 🖼️ 【3】画像＋翻訳メニュー作成機能
- 写真付きメニューの自動生成
- メニュー名、説明、価格、アレルギー表示を整形
- レスポンシブデザイン対応

### 🔊 【4】音声読み上げ・発音支援機能
- Web Speech API を使用した各言語の音声読み上げ
- 客・スタッフ双方が使える接客支援機能
- ワンクリックで簡単に音声再生

### 🚫 【5】アレルギー・宗教対応表記
- 卵、乳、小麦、甲殻類、豚肉などをアイコンで表示
- ベジタリアン、ビーガン、ハラール、グルテンフリー対応
- 視覚的に分かりやすい表示

### ☁️ 【6】クラウド一元管理・リアルタイム更新
- 管理画面でメニューを更新すると全言語に即時反映
- 季節メニューや価格変更も簡単
- JSON形式でのエクスポート・インポート機能

### ✏️ 【7】カスタム翻訳・修正機能
- AI翻訳結果を店舗側で修正・保存可能
- 修正した翻訳は次回以降に自動反映
- 「意訳」や「ニュアンス調整」が可能

### 📊 【8】メニュー閲覧分析機能
- どの言語・どのメニューが多く閲覧されているか分析
- 人気メニューを国籍別に把握
- 販売戦略・マーケティングに活用可能

## 🚀 セットアップ

### 必要環境
- Node.js 18以上
- npm または yarn

### インストール

```bash
# リポジトリのクローン
cd /home/user/webapp/restaurant-translate

# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev
```

開発サーバーは http://localhost:3000 で起動します。

### ビルド

```bash
# プロダクションビルド
npm run build

# プロダクションサーバーの起動
npm start
```

## 🎯 使い方

### 1. メニューの閲覧（顧客向け）

1. トップページにアクセス
2. 右上の言語セレクターから希望の言語を選択
3. メニュー項目をスクロールして閲覧
4. 🔊ボタンをクリックして音声で聞く
5. アレルギー情報や食事制限マークを確認

### 2. QRコードの生成

1. トップページの「QR Code」ボタンをクリック
2. 表示されたQRコードをダウンロードまたは印刷
3. テーブルに設置して顧客がスキャンできるように

### 3. メニュー管理（店舗向け）

1. `/admin` にアクセスして管理画面を開く
2. レストラン基本情報を編集
3. カテゴリごとにメニュー項目を追加・編集・削除
4. 変更を保存してエクスポート

### 4. アクセス分析

1. `/analytics` にアクセス
2. 言語別閲覧数、人気メニューTOP10を確認
3. インサイトを活用して販売戦略を立案

## 🔧 技術スタック

- **フロントエンド**: Next.js 14, React 18, TypeScript
- **スタイリング**: Tailwind CSS
- **QRコード生成**: qrcode.react
- **アイコン**: Lucide React
- **音声読み上げ**: Web Speech API
- **データ管理**: JSON形式（デモ版）

## 🌟 主な特徴

### 飲食業に特化した翻訳精度
一般的な翻訳APIでは正確に訳せない飲食用語を、専用辞書で高精度に翻訳。

### 視覚的に分かりやすいUI
画像、アイコン、バッジを活用し、言語が読めなくても直感的に理解できるデザイン。

### オフライン対応（PWA化可能）
一度表示したメニューはキャッシュに保存され、通信環境が悪くても閲覧可能。

### リアルタイム更新
管理画面での変更が即座に全言語・全デバイスに反映。

## 📊 アナリティクス活用例

- **英語圏の顧客が多い** → 英語メニューの翻訳精度を重点チェック
- **特定メニューの閲覧が多い** → 推奨メニューとして前面に配置
- **韓国語の閲覧が増加** → 韓国語メニューの充実化

## 🔐 セキュリティとプライバシー

- 個人情報は収集しません
- 言語設定はブラウザのローカルストレージに保存
- アナリティクスデータは匿名化

## 📝 カスタマイズ

### メニューデータの変更

`src/data/sampleMenu.ts` を編集して、自店舗のメニューに変更できます。

### 翻訳辞書の追加

`src/lib/foodDictionary.ts` に新しい用語と翻訳を追加できます。

### デザインのカスタマイズ

`tailwind.config.js` と `src/app/globals.css` でテーマカラーやスタイルを変更できます。
