## 🚀 使い方

### 1. フォーマットとカラーを選択
1. 画面上部の **フォーマット選択エリア** から好きなフォーマット（1～30）を選択
2. **配色テーマ** から好きな色を選択
3. リアルタイムでプレビューに反映されます

### 2. データ入力
1. **月タブ** から入力したい月を選択（1月～6月）
2. 各項目に必要なデータを入力：
   - 基本情報（発行年月、社員名、会社名）
   - 勤怠情報（労働日数、労働時間、残業時間）
   - 支給項目（基本給、通勤手当）
   - 控除項目（所得税、住民税、健康保険、厚生年金、雇用保険）
3. 入力内容は自動保存されます

### 3. 他の月を入力
- 月タブを切り替えて、同様に2月～6月のデータを入力
- 入力済みの月は **緑色** で表示されます

### 4. PDF出力
1. 全ての月のデータ入力が完了したら
2. **🖨️ PDF出力** ボタンをクリック
3. 印刷設定：
   - 用紙サイズ：**A4 横向き**
   - 余白：デフォルト
   - **背景のグラフィック：ON** ← 重要！
4. PDFとして保存または印刷

## 💾 データ保存

- 入力したデータは **localStorage** に自動保存されます
- ブラウザを閉じても次回起動時にデータが復元されます
- **🗑️ クリア** ボタンで現在の月のデータを削除できます

## 🖨️ 印刷設定（推奨）

### Google Chrome / Microsoft Edge
1. Ctrl+P（Windows）または Cmd+P（Mac）で印刷ダイアログを開く
2. 送信先：「PDFに保存」を選択
3. 用紙サイズ：**A4 横向き**
4. 余白：デフォルト
5. オプション：
   - ✅ **背景のグラフィック：ON**（必須！）
6. 「保存」をクリック

### Firefox
1. Ctrl+P（Windows）または Cmd+P（Mac）で印刷ダイアログを開く
2. 「Microsoft Print to PDF」または「PDFに保存」を選択
3. 用紙サイズ：**A4 横向き**
4. ページ設定 → 書式とオプション：
   - ✅ **背景色と画像を印刷**（必須！）
5. 「保存」をクリック

## 🔧 トラブルシューティング

### Q: 印刷時に色が表示されない
**A**: 印刷設定で「背景のグラフィック」または「背景色と画像を印刷」を **ON** にしてください。

### Q: データが消えてしまった
**A**: ブラウザのキャッシュやCookieを削除するとlocalStorageのデータも消えます。重要なデータは定期的にPDF保存してください。

### Q: レイアウトが崩れる
**A**: 印刷設定で用紙サイズを「A4 横向き」に設定してください。余白は「デフォルト」または「なし」を選択してください。

### Q: 数字が正しく計算されない
**A**: 入力欄に半角数字を入力してください。全角数字や文字が含まれていると計算できません。
