# シフト管理アプリ - AI搭載の次世代シフト・勤怠管理システム

AI搭載の包括的なシフト・勤怠管理システム。飲食店・小売店・サービス業向けに最適化されています。

## 🚀 主要機能

### 1. **AIシフト自動生成**
- ワンクリックでシフト作成
- スタッフの希望を考慮
- 人員配置の最適化
- 人件費の最適化（最大15%削減）

### 2. **シフトカレンダー**
- 月次・週次・日次の3つの表示モード
- スタッフ情報の表示
- レスポンシブデザイン
- モバイル対応

### 3. **シフト管理**
- 手動でのシフト追加
- 一括公開機能
- 編集・削除機能
- スタッフ別表示

### 4. **勤怠管理**
- 3つの打刻方法：
  - 手動打刻
  - QRコード打刻
  - GPS位置情報打刻
- 労働時間の自動計算
- 勤怠履歴の管理
- 管理者による全スタッフ閲覧

### 5. **評価・フィードバックシステム**
- 5段階評価システム
- 管理者による評価作成・編集
- スタッフによる評価閲覧
- フィードバック機能
- 目標設定機能
- モチベーション統計

### 6. **レポート機能**
- 月別選択機能
- 実勤怠データからの自動計算：
  - 今月の総労働時間
  - 今月の人件費
- スタッフ別統計表
- 労働コストシミュレーション

### 7. **スタッフ管理**
- スタッフのCRUD操作
- 役割管理（管理者/マネージャー/スタッフ）
- 時給設定
- 検索機能

### 8. **ダッシュボード**
- 週次シフト概要
- 当日出勤スタッフ数
- 労働時間統計
- リアルタイム更新

### 9. **認証・権限管理**
- JWT認証
- bcryptパスワードハッシュ化
- 3つの役割（管理者/マネージャー/スタッフ）
- 機能別アクセス制御

### 10. **店舗・ポジション管理**
- 複数店舗対応
- ポジションのカスタマイズ
- カラーコーディング

## 🛠 技術スタック

### バックエンド
- **Node.js** - ランタイム環境
- **Express** - Webフレームワーク
- **SQLite** - データベース（10テーブル）
- **bcryptjs** - パスワードハッシュ化
- **jsonwebtoken** - JWT認証
- **better-sqlite3** - SQLiteドライバー

### フロントエンド
- **React 18** - UIライブラリ
- **Vite** - ビルドツール
- **Tailwind CSS** - スタイリング
- **React Query** - データフェッチング
- **Zustand** - 状態管理
- **React Router** - ルーティング
- **Sonner** - トースト通知
- **Lucide React** - アイコン
- **date-fns** - 日付操作

## 📦 インストール

```bash
# リポジトリをクローン
git clone https://github.com/kazunarihonda83-jpg/-kazunarihonda83-jpg.git
cd shift-management-app

# 依存関係をインストール
npm install

# データベースを初期化（自動実行）
# 初回起動時に自動的にデータベースが作成され、サンプルデータがシードされます
```

## 🚀 起動方法

### 開発モード
```bash
# サーバーとクライアントを同時起動
npm run dev
```

### 個別起動
```bash
# バックエンドのみ起動
npm run server

# フロントエンドのみ起動
npm run client
```

### ビルド
```bash
# 本番用ビルド
npm run build

# プレビュー
npm run preview
```

## 🌐 APIエンドポイント

### 認証
- `POST /api/auth/login` - ログイン
- `POST /api/auth/register` - 新規登録
- `GET /api/auth/me` - 現在のユーザー情報取得

### シフト
- `GET /api/shifts` - シフト一覧取得
- `POST /api/shifts` - シフト作成
- `POST /api/shifts/generate` - AIシフト生成
- `POST /api/shifts/publish` - シフト公開
- `GET /api/shifts/simulate/labor-cost` - 人件費シミュレーション

### 勤怠
- `POST /api/attendance/clock-in` - 出勤打刻
- `POST /api/attendance/clock-out` - 退勤打刻
- `GET /api/attendance/today` - 本日の勤怠取得
- `GET /api/attendance/history` - 勤怠履歴取得
- `GET /api/attendance/all` - 全スタッフの勤怠取得（管理者のみ）
- `GET /api/attendance/stats` - 勤怠統計取得

### 評価
- `GET /api/evaluations` - 評価一覧取得
- `POST /api/evaluations` - 評価作成
- `PUT /api/evaluations/:id` - 評価更新
- `POST /api/evaluations/feedback` - フィードバック作成
- `POST /api/evaluations/goals` - 目標作成

### ポジション
- `GET /api/positions` - ポジション一覧取得
- `POST /api/positions` - ポジション作成
