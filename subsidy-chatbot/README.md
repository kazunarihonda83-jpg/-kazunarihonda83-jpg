# 業務改善助成金Q&Aチャットボット

業務改善助成金に関する質問に自動で回答するWebアプリケーションです。

## 機能

- **質問検索**: ユーザーの質問に対して、関連するQ&Aを自動検索
- **カテゴリー閲覧**: 7つのカテゴリーからQ&Aを一覧表示
- **類似度スコア**: 質問の関連度を表示
- **レスポンシブデザイン**: PCとモバイルの両方に対応

## 技術スタック

- **バックエンド**: Flask (Python)
- **フロントエンド**: HTML, CSS, JavaScript
- **データ**: JSON形式のQ&Aデータベース

## セットアップ

1. 依存関係のインストール:
```bash
pip install -r requirements.txt
```

2. アプリケーションの起動:
```bash
python app.py
```

3. ブラウザでアクセス:
```
http://localhost:5000
```

## Q&Aカテゴリー

1. 対象事業場等の要件について
2. 事業場内最賃とその支払対象労働者について
3. 賃金の引上げについて
4. 業務改善について
5. 不交付となる事由
6. 交付申請について
7. 報告事項について
8. その他

## 使い方

### 質問検索
1. 上部の検索ボックスに質問を入力
2. 「検索」ボタンをクリック
3. 関連度の高いQ&Aが表示されます

### カテゴリー閲覧
1. 左サイドバーのカテゴリーをクリック
2. そのカテゴリーのすべてのQ&Aが表示されます

## API エンドポイント

- `GET /` - メインページ
- `POST /api/search` - Q&A検索
- `GET /api/categories` - カテゴリー一覧取得
- `GET /api/category/<category_id>` - カテゴリー詳細取得
- `GET /api/stats` - 統計情報取得

## 検索アルゴリズム

- 質問文の類似度比較（70%）
- キーワードマッチング（30%）
- 上位5件の結果を表示

## カスタマイズ

Q&Aデータを追加・編集するには、`data/qa_data.json`ファイルを編集してください。

形式:
```json
{
  "id": "q番号",
  "question": "質問文",
  "answer": "回答文",
  "keywords": ["キーワード1", "キーワード2"]
}
```
